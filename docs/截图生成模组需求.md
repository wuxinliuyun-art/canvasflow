# CanvasFlow 截图生成模组需求

## 目标

在当前 `.NET 10 WPF + WebView2` 桌面架构中增加一个独立的原生截图工具窗口，用于反复截取固定屏幕区域，并将截图配合预设提示词直接提交到 CanvasFlow 的 AI 任务队列。

该模组不绑定建模软件或窗口名称，不恢复旧 Electron/浏览器截图面板，也不调用 PowerShell、系统截图命令或额外程序。

## 窗口形态

- 使用 WPF 原生窗口，默认置顶。
- 关闭按钮只隐藏窗口，不退出 CanvasFlow。
- 可从设置面板的“截图工具”分类重新打开。
- 记住窗口位置、折叠状态和置顶状态。
- CanvasFlow 主程序退出时销毁截图窗口及临时框选层。

### 折叠状态

仅保留以下操作：

1. 截图。
2. 发送任务。
3. 显示或收起预览。

### 展开状态

在折叠状态的功能之外，增加：

- 重新设置截图区域。
- 从全局“自定义文字”素材中选择一条作为默认提示词。
- 模型、分辨率、画质、比例和生成数量。
- “发送前自动重新截图”开关，默认关闭。
- 置顶开关。

## 截图逻辑

- 截取固定屏幕矩形区域，不绑定具体软件窗口。
- 用户可随时通过全屏框选层重新选择区域。
- “截图”只更新最近截图，不发送 AI 任务。
- “发送任务”默认使用最近一次有效截图。
- 开启“发送前自动重新截图”后，发送前自动重新截取保存区域。
- 框选时支持 `Esc` 取消；取消或异常后必须恢复截图窗口。
- 空区域和过小区域不得保存或提交。
- 截图区域按显示器标识、显示器边界特征和相对比例保存。
- 显示器被移除、分辨率改变、DPI 缩放改变或保存区域越界时，区域失效并要求重新框选。

## AI 任务

- API Key 复用 CanvasFlow 设置中由 Windows DPAPI 保存的密钥。
- 默认提示词从 `data/custom-library.json` 的全局自定义文字中读取。
- 截图作为参考图，所选自定义文字作为提示词。
- 模型与返回格式继续兼容当前 GPT Image 等同步、异步、URL 和 Base64 响应。
- 任务必须进入画板现有的全局 AI 队列，沿用最多同时运行 5 个任务的限制。
- 生成数量拆分为独立队列任务，等待中的任务可继续使用现有暂停、恢复、排序和删除能力。
- 结果自动保存到 `export/ai_generated/`。
- 第一版不自动在画布中创建图片节点。

## 预览

- 预览区同时显示最近截图和最近一次生成结果。
- 多张结果支持切换查看。
- 可单独收起预览，避免遮挡其他软件。
- 没有截图、截图区域失效、API Key 缺失、请求失败和保存失败时显示三段式错误提示：发生了什么、可能原因、建议解决办法。
- 截图失败时保留上一次有效截图；生成失败时保留已有截图和历史结果。

## 数据与安全

- 设置保存到 `data/screenshot-settings.json`，采用临时文件替换的原子写入方式。
- 临时截图保存到 `data/screenshots/`，不进入画布的 `data/assets/originals/` 素材仓库。
- AI 结果仍保存到 `export/ai_generated/`。
- API Key 不写入截图设置、项目 JSON、日志或任务消息。
- 不使用 PowerShell、CMD、Shell COM、系统截图命令、Electron或额外进程。

## 生命周期

- 创建：首次从设置打开窗口；没有截图区域时引导框选。
- 编辑：可重新框选、切换提示词和修改 AI 参数。
- 保存：窗口状态和参数自动保存，截图文件按最新有效截图更新。
- 恢复：重新启动后恢复窗口位置、折叠和置顶状态；截图区域有效时继续使用。
- 删除：重新框选替换旧区域；临时截图允许由程序清理，但不得删除生成结果。
- 销毁：主程序退出时关闭窗口和框选层，取消尚未提交的截图操作；已进入 AI 队列的任务按现有退出保存规则处理。

## 第一阶段验收

- 设置中能打开原生截图窗口。
- 窗口可置顶、折叠、移动、隐藏并恢复位置。
- 可在多显示器和 Windows 缩放环境下框选固定区域。
- 可手动截图并在预览区查看清晰结果。
- 显示器环境变化后旧区域会安全失效。

## 第二阶段验收

- 能读取全局自定义文字并保存选择。
- 能配置模型、分辨率、画质、比例和数量。
- 能将截图任务送入现有队列，并在主画板任务队列中查看。
- 多张结果保存到 `export/ai_generated/`，且不自动添加到画布。
- 缺少 API Key、请求失败、截图失败和保存失败均有可执行的错误提示。
