# CanvasFlow UI 规范

本规范基于现有代码实测整理(2026-10),适配原生 CSS 架构(无框架、CSS 变量令牌)。
目标:新增或修改界面时,样式决策有唯一出处; AI 辅助开发时可作为约束性提示词使用。

## 1. 颜色:只用变量,禁止裸色值

所有颜色必须引用 `styles.css` 顶部 `:root` 的语义变量,组件样式里**不得出现十六进制或 rgba 裸色值**(阴影、遮罩等确实需要独立透明度组合的,先提为新变量再引用)。

### 核心语义令牌(唯一权威定义,禁止重复定义)

| 变量 | 用途 | 不得再用 |
|---|---|---|
| `--bg` | 画布/页面底色 | |
| `--panel` / `--panel-solid` | 面板底(带透明/纯色) | |
| `--panel-2` | 面板内分区、嵌套块 | |
| `--text` | 正文 | |
| `--muted` | 次要文字(对比度 ≥4.5:1) | |
| `--line` | 边框、分隔线 | |
| `--accent` | 主操作、强调 | |
| `--accent-soft` | 强调背景、悬浮态 | |
| `--selected` | 画布选区/连线选中色(中性:浅色主题为灰、深色主题为主题白) | |
| `--primary` | **主交互蓝**:进行中状态、激活入口、运行按钮、端口可连接 | `#2f80ed`、`#4f7cff` 散值 |
| `--drop-indicator` | 拖放落点指示(引用 `--primary`) | |
| `--danger` | 危险操作、错误 | `#dc2626`、`#ef4444`、`#b91c1c` 散值 |
| `--success` / `--warning` | 在线/完成、下载中/离线警示 | `#22c55e`、`#f59e0b` 散值 |
| `--inverse-text` | 深色块/图片浮层上的白字 | `color: #fff` 散值 |
| `--node-control` | **节点内部唯一控件灰**:下拉框、节点内按钮、文字框、参数行、预览块(暗色 `#1c1c21`,比节点身亮一档;浅色 `#f2f2f5`) | 节点内禁止再出现其他灰度 |
| `--canvas-grid` | 画布网格 | |
| `--canvas-cross` / `--canvas-dot` | 画布背景"网格 + 十字焦点"/"点状"模式的焦点标记(画布装饰,非交互色) | |
| `--radius` | 圆角(8px),大容器可 2 倍 | |

规则:
- 新增令牌先加进 `:root`(浅色)和 `.theme-dark`(深色),再使用;只写浅色不写深色视为 bug。
- `--selected` 语义为"画布选中",`--primary` 语义为"进行中/主交互",`--utility-hover` 语义为"功能入口悬浮",不得混用。
- 主题只允许在 `:root` 与主题选择器处写值,组件层只读。

## 2. 间距:4px 基准网格

以 4px 为最小刻度,常用档位:**4 / 8 / 12 / 16 / 20 / 24 / 32**。
- 同层级留白统一:面板内边距 16px,控件间 8px,相关控件组内 4px,区块间 24px。
- 现存的 3/5/7/9/10/11/13px 等"奇数档"是历史遗留,**改到哪行修到哪行**,不做全局替换;禁止新增非 4 倍数间距(1/2px 仅限边框与微调,6px 允许用于紧凑图标内距)。

## 3. 字号与排版

| 档位 | 值 | 用途 |
|---|---|---|
| 最小可读 | 12px | 辅助说明、徽标、时间戳 |
| 正文小 | 13px | 面板正文、列表项 |
| 正文 | 14px | 输入框、下拉、主要面板文字 |
| 小标题 | 16px | 分区标题 |
| 标题 | 18–22px | 面板标题、弹窗标题 |

- **禁止新增 12px 以下字号**;存量 9–11px 逐处迁移到 12px。
- 正文本行高 1.4–1.6;按钮/标签/单行控件可用 1。
- 字体族全局统一为现有两条链(西文 Inter、中文 HarmonyOS Sans SC 链),组件不得自带 font-family。

## 4. 层级(z-index 刻度)

固定 6 档,新增层级就近取档,禁止发明新数字(尤其禁止 12000 这类离群值):

| 档 | 值 | 用途 |
|---|---|---|
| 1 | 1–9 | 节点内部元素、画布装饰 |
| 2 | 10–19 | 节点悬浮态、连线拖拽层 |
| 3 | 20–29 | 侧栏、队列面板 |
| 4 | 30–39 | 顶部工具栏、浮动按钮 |
| 5 | 100–299 | 弹窗、抽屉、onboarding |
| 6 | 300+ | toast / 全局通知(最高,全局仅此一个) |

## 5. 动效

- 微交互过渡 120–200ms,弹层出入 150–250ms,统一 `ease-out`。
- 只过渡 `opacity` / `transform`;**按钮按压反馈用透明度,禁止 transform**(会缩小命中区,见 AGENTS.md 踩坑记录)。
- 全局已启用 `prefers-reduced-motion` 适配,新增动画无需单独处理,但不得用 `!important` 覆盖该媒体查询。

## 6. 交互与无障碍

- 图标按钮必须有 `aria-label`(现有 28 处为基准,新增不得缺失)。
- 可点击元素必须有 `cursor: pointer` 与可见焦点态(`:focus-visible`)。
- 异步操作期间按钮必须禁用并给出进行中状态,禁止无反馈等待。
- 图片节点内的 `<img>` 一律 `pointer-events: none`,事件交给容器(见 AGENTS.md 踩坑记录)。
- 文字对比度 ≥4.5:1;浅色 `--muted` 若再调浅需先验证对比度。

## 7. 组件与样式复用

- 新 UI 优先复用现有类(`.btn` 系、面板系、`.pill` 等),同形态第二次出现必须抽公共类,禁止第三次复制粘贴。
- 修改面板/列表类渲染后,必须实际打开对应面板验证渲染未中断(见 AGENTS.md"误粘代码碎片"踩坑记录)。
- 改动任何前端文件后,同步递增 `index.html` 中对应资源的 `?v=` 版本号(日期+序号,如 `20261004`),否则热更新会被缓存吞掉。

## 8. 与 shadcn/ui 提示词的对应关系

外部的 shadcn 规范(仅用组件库、8px 间距、无随机颜色、无渐变、优先复用)在 CanvasFlow 的等价翻译:
- "仅使用 shadcn/ui 组件" → 仅使用本规范第 1 节的令牌与第 7 节的公共类;
- "使用 Tailwind" → 使用 CSS 变量,不引入内联样式;
- "不要随机颜色" → 第 1 节禁裸色值;
- "8px 间距系统" → 第 2 节 4px 网格(密度更高的工具型界面取 4px 基准);
- "优先已有组件" → 第 7 节。
