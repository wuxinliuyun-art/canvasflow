# 分区抠图

双击有图片的图片节点、AI 绘图节点或角度节点进入图片编辑，在底部工具栏「裁剪」旁选择「分区抠图」。右键菜单不再重复提供该入口。

1. 在原图上拖动添加选框。右侧列表与图上的框使用相同颜色和编号。
2. 点击「添加选框」可绘制重叠选框；点击右侧「原图」回到总览。
3. 每个选框右侧的 × 可直接取消对应选框。
4. 选择选框后，左侧只显示该区域，支持适合窗口、100%、200%、400% 缩放。通过「擦除画笔」移除像素，「恢复画笔」补回原图；各选框独立保存最近八次撤销。
5. 完成框选后点击「确认」，弹窗列出生成张数、当前 API 对应模型与固定提示词。点击「开始抠图」才提交；点击「返回调整」或按 Esc 返回选框，保留全部编辑。

每个任务只发送自己的选区图，固定提示词为「将图片中主体抠出、透明背景」。APIMart 使用 gpt-image-2.5-flare，AGToken 继续使用 gpt-image-2.5，每个选区生成一张结果；APIMart 沿用提交加轮询，AGToken 沿用同步 edits，两套请求格式与 Key 分别处理。排队期间切换 API 不会改变已提交选区任务的 API 类型。

不会生成待连接的裁剪图片节点或 AI 绘图节点，也不需要手动连线。结果沿用现有队列，生成后显示为原图旁的结果图片节点，保存生成提示词和选框坐标。进度与失败原因可在任务队列查看。

选框、手动修整和抠图模型选择在关闭窗口或提交时保存到原节点，随项目持久化；再次打开时恢复，原图内容发生变化时不套用旧选区。每个选框仍可通过 × 删除。修整的撤销栈仅在当前窗口保留；未配置当前 API Key 或原图已有运行任务时，会保留窗口与选框并给出提示。在线模型路径不依赖本地服务；选择「本地 BiRefNet」时不检查 API Key。

## 验证

- 真实浏览器检查双击图片后的「分区抠图」入口、右键菜单无重复入口、多个彩色选框、逐项 ×、提交前确认弹窗、返回与 Esc 保留选框，以及缺少 Key 时保留选框。
- 用本地模拟接口完成 APIMart 两个选区与 AGToken 单个选区的排队、请求、结果保存和画布落位；未调用付费上游生成。
- 独立检查两套 API 的精确提示词、模型、各自 Key 槽、每任务一张参考图，以及切换设置后仍保持原 API。

## 本地 BiRefNet

仍然先手动框选、擦除或恢复，再在底部「抠图模型」选择「本地 BiRefNet」。确认后逐选区调用已安装的「自动抠图（通用模型）」拓展；每个选区生成透明 PNG，保留手动擦除蒙版，并沿用队列、保存和结果落位。

无需提前运行本地服务或启动脚本。CanvasFlow 会通过现有拓展执行接口自动启动 Python；拓展优先使用 `python-path.txt` 指定的 Python 3.11–3.13，并建立自己的 `.venv`。失效路径会自动回退，依赖镜像缺包时自动改用官方 PyPI。拓展未安装或运行失败时保留选框并显示错误，不会转用付费 API。

2026-10-15：实际调用本地 CUDA 服务验证 health 与 matting，返回 128×128 RGBA PNG，alpha 范围 0–255。浏览器验证因测试浏览器错误页访问策略阻断未完成；桌面 WebView2 联调尚未验证。
