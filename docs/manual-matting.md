# 分区抠图

在有图片的图片节点、AI 绘图节点或角度节点上右键，选择「分区抠图」。此入口独立于「编辑图片」。

1. 在原图上拖动添加选框。右侧列表与图上的框使用相同颜色和编号。
2. 点击「添加选框」可绘制重叠选框；点击右侧「原图」回到总览。
3. 每个选框右侧的 × 可直接取消对应选框。
4. 选择选框后，左侧只显示该区域，支持适合窗口、100%、200%、400% 缩放。通过「擦除画笔」移除像素，「恢复画笔」补回原图；各选框独立保存最近八次撤销。
5. 完成框选后点击「确认」，弹窗列出生成张数、GPT Image 2.5 模型、当前 API 与固定提示词。点击「开始抠图」才提交；点击「返回调整」或按 Esc 返回选框，保留全部编辑。

每个任务只发送自己的选区图，固定提示词为「将图片中主体抠出、透明背景」。模型使用当前 API 对应的 gpt-image-2.5，生成一张结果；APIMart 沿用提交加轮询，AGToken 沿用同步 edits，两套请求格式与 Key 分别处理。排队期间切换 API 不会改变已提交选区任务的 API 类型。

不会生成待连接的裁剪图片节点或 AI 绘图节点，也不需要手动连线。结果沿用现有队列，生成后显示为原图旁的结果图片节点，保存生成提示词和选框坐标。进度与失败原因可在任务队列查看。

选框、手动修整和抠图模型选择在关闭窗口或提交时保存到原节点，随项目持久化；再次打开时恢复，原图内容发生变化时不套用旧选区。每个选框仍可通过 × 删除。修整的撤销栈仅在当前窗口保留；未配置当前 API Key 或原图已有运行任务时，会保留窗口与选框并给出提示。GPT Image 2.5 路径不依赖本地服务；选择「本地 BiRefNet」时不检查 API Key。

## 验证

- 真实浏览器检查右键入口、编辑工具栏移除入口、多个彩色选框、逐项 ×、提交前确认弹窗、返回与 Esc 保留选框，以及缺少 Key 时保留选框。
- 用本地模拟接口完成 APIMart 两个选区与 AGToken 单个选区的排队、请求、结果保存和画布落位；未调用付费上游生成。
- 独立检查两套 API 的精确提示词、模型、各自 Key 槽、每任务一张参考图，以及切换设置后仍保持原 API。

## 本地 BiRefNet

仍然先手动框选、擦除或恢复，再在底部「抠图模型」选择「本地 BiRefNet」。确认后逐选区调用本机 127.0.0.1:8790/matting；每个选区生成透明 PNG，保留手动擦除蒙版，并沿用队列、保存和结果落位。

运行项目根目录 `启动本地抠图.cmd` 可复用 F:\卡牌游戏demo 的 Python 环境与抠图服务。启动器为 Numba 指定项目内缓存，避免中文路径下默认缓存初始化失败。模型使用服务当前加载的模型（默认 birefnet-general）；该服务不支持在请求中切换权重。服务离线或超时时保留选框并显示错误，不会转用付费 API。
