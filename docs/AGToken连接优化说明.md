# AGToken 连接优化（2026-11-23）

## 已修改

- Windows 桌面：建连上限 30 秒；生成请求仍保留 600 秒等待时间。
- Windows 桌面：空闲连接 30 秒后回收，连接池生命周期 5 分钟，减少长期复用失效连接，并允许后续连接重新解析 DNS；不会中断正在生成的请求。
- Windows 与 Node 服务：只对能确认发生在 TLS 握手阶段的临时传输中断，等待 1 秒后重试一次。
- 证书校验失败、收到 HTTP 错误、发送后的断线及结果接收中断，不自动重发业务请求。
- Windows 区分 TLS、DNS 与结果未知错误，并记录错误类别和尝试次数；Node 同步提供握手阶段与结果未知提示，并处理响应中途断开。

## 默认代理的含义

Windows 桌面沿用 .NET 默认代理配置：可能读取 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY、NO_PROXY 等环境变量，或者 Windows 用户代理设置。代理软件退出但系统配置残留时，可能立即连接失败。不同电脑即使运行相同程序，也可能走不同线路。

这次保留默认代理兼容性，不自动切换为直连，不跳过证书校验。Node 服务原有 https.request 与 Windows 默认代理行为不完全相同，此次没有改变其代理机制。

## 生效方式与手动检查

- Windows 源码运行：关闭当前程序后重新运行项目的桌面启动 BAT，以重新编译并启动。已安装版本需重新构建完整安装包后更新；仅更新界面不会替换桌面网络实现。
- Node 服务：重新启动服务进程；mac 内嵌服务需重新打包应用。
- 请在原来容易报错的电脑上正常提交任务，观察瞬间失败是否减少；仍失败时保留完整错误和发生时间，并用手机热点对比。
- 如提示“任务结果未知”，先查站点任务记录，确认后再决定重试。
