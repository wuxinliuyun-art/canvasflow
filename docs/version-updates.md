# CanvasFlow 版本功能更新说明汇总

按版本从新到旧排列。发布新版本时，在文件顶部（标题行下方）新增一节，格式与既有条目保持一致。

---

## v2.7.4

1. **AI 对话节点**：支持结合上游文字与参考图进行对话，保留关键词并更新最新结果，支持停止生成与清空对话历史。
2. **批量生成提示词**：开启批量提示词后，AI 按编号输出多条方案，并自动拆分为独立文字节点；普通对话中符合编号格式的回复也可自动拆分。
3. **文字节点变量选择**：文字中匹配到已定义的变量时，可直接选择变量值，组合输出提示词，减少重复修改。
4. **串联提示词组合**：同一线上的文字、变量节点按上游到下游顺序合并；多条支线分别处理，避免不同任务之间的提示词互串。
5. **文字按行拆分**：多行文字节点支持右键「按换行拆分为文字节点」，每个非空行生成一个节点，并自动避让已有节点。
6. **文字重合合并**：将有内容的文字节点拖到另一个文字节点上，可按画布位置顺序合并文案，并自动转移连线。设置中可单独关闭此功能。
7. **新增浏览器插件**：配合浏览器生图节点，支持在 Gemini、ChatGPT 和自定义站点提交提示词与参考图，并将生成结果回传画布；也支持在网页上按住图片向下拖动，直接传入画布并创建图片节点。
8. **图片裁剪**：图片编辑器新增裁剪功能，可直接选择并保留所需区域。
9. **分区抠图**：图片节点右键新增「分区抠图」，支持在一张图片上框选多个区域，使用 GPT Image 2.5 分别生成抠图结果。支持擦除与恢复画笔、预览缩放和撤销；选区与修整内容随项目保存，重新打开可继续调整。
10. **Photoshop UXP 交互面板**：新增适用于 Photoshop 2022（23.3）及以上版本的 UXP 面板，支持将当前图层或合并图像传回画布，保留原有 CEP 面板。
11. **Mac/Windows 共用界面更新包**：两端接入同一份界面热更新包，统一校验与版本兼容规则；涉及宿主程序变化时，仍使用对应平台的完整安装包。
12. **生成图片命名优化**：新生成图片采用「日期—项目名称—序号」命名，便于查找与归档，兼容原有素材记录。
13. **导出文件防覆盖**：图片、项目 JSON、PPT 等通过统一导出接口保存时，同名文件自动追加序号，保留已有文件。
14. **用户文件保留优化**：调整安装器清理规则，避免卸载或覆盖安装时误删导出图片、项目数据及拓展结果。
15. **画布文字标注**：双击画布空白处即可创建文字标注，可拖动移动、双击改名、选中后按 Delete 删除；蓝色文字的大小不随画布缩放变化，随项目一起保存。原「双击居中显示画布」行为由该功能替代。
