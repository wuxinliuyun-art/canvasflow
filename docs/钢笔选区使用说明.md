# 图片编辑：钢笔与选区

钢笔与选区操作已合并进原有的底部黑色工具条，不再显示独立的第二条。在工具条点击「钢笔选区」。打开自由上色或材质改色后，这条工具栏仍保留；点击左侧调色盘的笔刷入口或右侧笔刷按钮可回到笔刷，点击「钢笔选区」继续编辑路径。右侧改色面板垂直居中。选区方式、闭合路径、取消选区、填充选区仅在选中钢笔时展开，切换到其他工具后收起；钢笔入口常显，底部重复的「笔刷」按钮已移除。钢笔不再提供界面操作说明入口；打开笔刷后，底部其他工具及左侧工具按钮继续显示。

- 单击添加角点；按住鼠标拖拽创建贝塞尔手柄。
- 拖动锚点移动它及两侧手柄；拖动手柄调整曲线，Alt 拖手柄可独立调整一侧。
- Alt 拖已有角点可重新拉出手柄。
- 点击首点或按 Enter 闭合路径；尚未闭合时，Ctrl/Cmd 拖首点可移动它。
- 当前路径闭合后仍可编辑。切换工具再返回钢笔，当前路径仍保留。
- 闭合后，在空白处点击开始下一条路径。此前的路径保留为选区，只有当前路径保留可拖动锚点；可用撤销返回上一条路径。
- 下拉选择「新建选区 / 加选 / 减选」，用于下一条路径；正在画的未闭合路径也可切换方式。开始新路径时按住 Shift 为加选，Alt 为减选。
- Delete / Backspace 删除所选锚点；Esc 放弃未闭合路径，闭合后 Esc 退出钢笔工具并保留选区。
- 「取消选区」清除路径和选区；不会清除已经画好的内容。

选区会限制画笔、箭头、矩形、橡皮和草图填色的范围。「填充选区」使用当前颜色填色，沿用「保留线稿」设置。自由上色和材质颜色修改仅使用钢笔选区限制落笔与输出范围，不会在打开笔刷时自动填满选区；实际涂抹后才会出现颜色。钢笔选区在笔刷面板打开期间也能修改，修改后范围立即同步。

只显示钢笔路径，不另外叠加像素选区虚线；切到笔刷时路径线仍保留，锚点和手柄仅在钢笔模式显示。这些提示位于独立显示层，不会写入结果图片。每笔绘画记录下笔时的选区，之后调整选区不会重绘之前的笔画。选区只在本次图片编辑会话保留。

选区编辑支持编辑器的撤销和重做；仅操作选区而没有修改图像时，关闭编辑器不会自动产生结果图片节点。裁剪会清除旧尺寸的选区，撤销裁剪可恢复。
