# CanvasFlow 浏览器生图桥

1. 保存并关闭 CanvasFlow，运行项目根目录的 `启动CanvasFlow-NET.bat`，使用新桌面程序。桌面版会自动启动浏览器任务桥，无需再启动服务版。
2. 在 Chrome 的 `chrome://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，选择当前 `browser-extension` 文件夹。已安装旧版时点击扩展卡片的“重新加载”。
3. 保持已安装插件的 Chrome 运行，点击插件“连接测试”，应显示已连接。首次使用目标站点时需要登录。
4. 创建“浏览器生图”节点，选择同一个站点，把文字和图片节点连入它。提示词框留空即可每次使用最新上游文字；填入内容则优先使用框内提示词。一次最多发送四张参考图。
5. 点击生成。插件会自动打开目标站点（已有对应标签页则切过去），随后填写提示词、粘贴参考图并点击发送，等待生成图片后回传画布。后台休眠时自动开页可能稍有延迟。站点布局变化时，在插件弹窗点击“校准此页面”，依次选择对话输入框和发送按钮，然后重试。

自定义站点需要填写完整网址，并先在该站点页面使用插件的校准入口。

插件使用网页可接收的粘贴和输入事件；不接管系统键鼠或系统剪贴板。站点必须支持图片粘贴或文件输入。请先用单个目标页面测试。

浏览器任务为串行执行，在画布任务队列中显示等待、执行、完成和失败状态。节点的“每次创建新对话”开关默认关闭；勾选后内置站点会在任务开始前打开新对话入口。自定义站点使用填写的网址作为入口，请填写该站点的新对话网址。遇到验证或限流提示时队列暂停，请手动处理，再在扩展弹窗点击“继续浏览器队列”。回车发送不被站点接受时自动改用发送按钮，操作节奏不能保证避免平台风控。
