# HTML 编辑独立 Demo（不发布）

直接双击 index.html，或通过工作区服务访问 /demos/html-editor/index.html。

支持导入 HTML、点击选中、父级选择、文字及样式回写、图片内嵌替换、源码编辑、撤销重做、浏览器本地自动保存和 HTML 导出。交互演示模式保留页面脚本。

拖选一行或部分文字后，字号、字重和文字颜色只作用于选区，源码中生成保留原有内容的 span。单击元素仍修改整个元素。对齐范围可选“整个页面”或“仅当前框内”；页面位置按预览视口（扣除 body 内边距）计算水平位置，以相对定位移动原元素，保留其原布局占位，可能与其他内容重叠。absolute/fixed/sticky 元素暂不自动移动，可选择合适父级。尚不支持跨页选区或动态 DOM 的文字回写。

## 主题、动画和浏览预设

- 主题：极简商务 / 纸张贴纸 / 暗色科技。
- 动画：淡入 / 上滑 / 缩放 / 逐条出现，支持系统减少动画偏好。
- 浏览：翻页演示（按钮、左右方向键、PageUp/PageDown）/ 长页滚动。
- 输入“纸张、逐条出现、翻页”等关键词可匹配三个选项，点击“应用预设”写入当前 HTML；主题与交互逻辑内嵌到源码，导出不依赖插件或第三方库。手动内联样式优先，不在切换时清除。
- 点击“加载三页示例”体验，可撤销回原文。默认不覆盖已有自动保存。
- 编辑模式关闭入场动画便于点选，交互演示模式展示效果；编辑时仍可用翻页按钮切页。
- “复制 AI 生成规范”用于生成前约定；规则另存为 GENERATION-SPEC.md。尚未调用模型。
- 仅对规范化 section[data-slide] 页面启用预设，不强行转换已有私有演示框架或任意网页。主题依赖语义变量，自定义写死的样式可能不随主题变化。长页切换到翻页仅使用已有分节，不自动拆分内容。

逻辑检查：`node --test demos/html-editor/presets.test.cjs`，覆盖预设资产幂等写入、导出内嵌运行时、翻页边界、滚动和旧 HTML 保护。此检查采用最小 DOM 替身，不替代浏览器视觉检查。

最新源码是保存依据，预览注入的辅助脚本和选中标记不会导出。动态生成且不存在于源码的元素暂不支持回写；复杂应用及外部资源不是完整离线打包。DOM 序列化会规范化 HTML 格式，不承诺保留原始空白或属性顺序。不含模型调用。

本目录独立于主程序，不添加正式入口。Windows csproj 和 Web 热更新脚本、mac 构建脚本均使用前端文件白名单，不包含 demos；不要把本目录复制进 publish 或 release。没有复制用户参考文件，也不修改 D:\CanvasFlow。
