主题与交互预设

规范化 HTML 可直接切换。旧文件保持原样，可先用三页示例体验。

编辑模式暂停动画，点击「交互演示」查看效果。预设随 HTML 导出，手动设置的局部样式优先保留。

元素属性

点击预览中的文字、图片或容器

含子元素的容器不整体替换文字，避免破坏结构。

拖选文字后，字号、字重、颜色只作用于选中文字；单击则修改整个元素。

交给 AI 继续修改

此 Demo 不调用模型。可将内容交给 AI，生成后再导入。每次应用源码和属性修改均可撤销。

自动保存仅存浏览器本地。导入页面的外部资源仍可能需要联网；脚本生成的动态元素暂不回写。
