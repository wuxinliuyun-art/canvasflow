# 自动抠图（通用模型）

本工具仅独立分发，不随 CanvasFlow 安装包、便携包、mac 包或界面热更新包发布。

将「自动抠图.zip」放进 CanvasFlow 的拓展目录，选择「解压到自动抠图\」。压缩包根目录直接包含扩展.json，正确结构是「拓展\自动抠图\扩展.json」，不要再套一层文件夹。已有完整的「自动抠图」文件夹时直接使用，不必重复解压。在设置 → 拓展中查看实际目录（安装版一般是安装目录下的「拓展」，源码版是仓库上级的「拓展」）。刷新拓展列表，添加「自动抠图（通用模型）」节点，连接一张或多张图片，点击执行。每张输入得到一张原尺寸透明 PNG 图片节点，无需框选、提示词、API Key 或本地服务。

也可以把图片放进本工具的 input 文件夹，双击「运行.cmd」，从 output 取结果。输出按输入文件名排序编号；重复运行会覆盖同名结果，其他旧结果会保留。画布调用时由画布清空并重建 output。

仅包含 BiRefNet 通用模型 birefnet-general，不含人像、massive 或双模型。不会改变图像主体，也不会生成新内容；复杂背景与半透明特效的效果取决于模型。

需要 Python 3.11 或更新版本且已加入 PATH。第一次使用缺少依赖时会在工具自己的 .venv 安装 CPU 运行依赖，需要联网；模型已经随包附带，安装完成后可离线使用。若首次安装超时，单独运行「运行.cmd」完成准备，再回画布执行。

要复用已有 GPU 环境：在本文件夹新建 UTF-8 的 python-path.txt，只写 Python 可执行文件的完整路径。例如本机现有环境为 `F:\卡牌游戏demo\.venv\Scripts\python.exe`。所选环境须已安装 rembg、onnxruntime（CPU 或 GPU 版）和 Pillow；可用 CUDA 时自动优先使用，否则 CPU 运行。无需复制整个环境。

模型来自 rembg 的 BiRefNet-general 发布权重（https://github.com/danielgatis/rembg/releases/tag/v0.0.0），使用 BiRefNet / rembg 的开源许可。本工具只读 input，把结果写到 output；运行环境及缓存保留在工具文件夹内。移动文件夹到另一台电脑后如 .venv 不可用，应删除该环境后重新准备依赖。
